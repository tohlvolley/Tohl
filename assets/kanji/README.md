加工内容：常用漢字に絞り、SVGから各画のパスを抽出してJSON/JavaScriptに変換。部品の字種・画数・筆画の種類を照合し、確認した追加の削除規則で対応表を生成しました。原典のSVG全体・字の説明・読みは再配布していません。パス・対応表の改変データもCC BY-SA 3.0で提供します。ゲームのプログラムと効果の割り当ては別のデータです。

常用漢字の字種・画数の事実一覧は、2010年の常用漢字表を転記した以下の表と照合しました。

- https://github.com/cjkvi/cjkvi-tables/blob/master/joyo2010.txt
- コミット：`096c25525fcc3933973da358c71b6be4b79442ee`
- 転記元として同ファイルに記載：https://ja.wikipedia.org/wiki/常用漢字一覧
- 正式な2,136字を採用。異体字・代用字体4字を追加して2,140字にする方式ではありません。`𠮟・塡・剝・頰` は正式字体で登録し、`叱・填・剥・頬` に置換しません。
- 「衷」は本体SVGが9画の異なる筆順のため、原典の `08877-Hyougai.svg` の10画データを使用しています。

## ファイル

- `joyo-2010.tsv`：正式字体と画数。字種・画数の事実のみ。
- `strokes.json` / `../../rpg-kanji-data.js`：2,136字の筆画パス・15,967件の対応表。
- `stroke-map.csv`：元字・総画数・選択画番号・結果・MP・根拠。
- `effects.json` / `effects.csv`：各字の初期効果2,136件。200字が個別初期設定、1,936字が明示的な汎用初期設定。ゲーム独自の設定で、言語学的な意味辞書ではありません。
- `excluded-conflicts.json`：同じ画番号から複数の字が候補になるため除外した組合せ。

## 生成と範囲

```sh
python tools/build-kanji.py /path/to/kanjivg
```

全画指定は2,136字すべてに登録し、1,895字に2画以上の部分抽出を登録しています。一画の横線を「一」とする対応も含みます。部首の原形をそのまま結果に置き換えません（氵→水、亻→人、灬→火などを自動許可しません）。部品にvariant指定があっても、正式な同字の画種と一致する場合だけ採用します。画の順序が違う部品に、そのまま削除規則を適用することもしません。複数の候補が競合する部分指定は除外します。

これはフォントからの完全な字形認識器ではなく、筆順データに基づく登録済み対応表です。全ての成立する部分集合を網羅したものではなく、部品字形の縮小・変形を許容する登録があります。元データの注釈由来の解釈も含むため、今後の個別修正が必要になる可能性があります。未登録の組合せには効果を発動せず、MP・ターンも消費しません。
