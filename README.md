# 字形活路 — RULE RUNNER

ステージ内の文章の空欄に漢字を一文字入力すると、その文字がルールと唯一の足場になる、ドット絵調のブラウザ用パズルです。初期10ステージと、ステージ作成機能を収録しています。

## ステージ内のルール

文章も入力欄もステージ内に配置されています。入力欄の位置と大きさはステージ制作者が決め、プレイヤーは移動できません。入力した漢字のドットだけが足場になり、文章のほかの文字はキャラクターと衝突しません。

1. ステージ内の空欄をクリックし、漢字一文字を自由入力します。
2. 日本語変換を確定したあと、Enterまたは「開始」で反映します。
3. 漢字が変わると、キャラクターをスタートに戻してジャンプ回数をリセットします。不成立・解釈できない入力は反映しません。
4. 「開始」でプレイを開始。出口ゲートに着けばクリアです。

未確定の入力はプレビューです。開始時に確定するため、見た目と当たり判定が食い違ったまま遊ぶことはありません。

### ジャンプはステージ全体の予算

**「このステージで三回まで飛べる。」なら、スタートからゴールまで合計3回です。着地しても残り回数は戻りません。** 地上からのジャンプに加え、空中では追加1回までジャンプできます。着地で空中の追加回数だけが戻り、ステージ全体の残り回数は戻りません。

- 一・二・三・十・百などの漢数字を解釈します。万・億・兆や壱・弐などにも対応します。
- 零／〇ならジャンプできません。
- 「二十三」のような複数字は、一文字の配置条件に合わないため反映できません。
- 同じ漢字の再確定、一時停止、着地では回数を回復できません。
- 漢字の変更、リトライ、落下後の再挑戦、新しいステージ開始で、スタートから新しい挑戦になります。

「体が［字］くなる。」の景では、意味に応じて移動速度・重力・大きさ・色などが変わります。その景の総ジャンプ回数はステージ設定によります。いずれの型でも、文を解釈できない入力は反映せず、現在のキャラクター・足場・ルールを保ちます。

任意の文章全般を理解するAIではありません。現在の文章の型は「このステージで［字］回まで飛べる。」「体が［字］くなる。」の2種類です。未対応の意味も解釈できない旨を表示します。プレイヤー向けのプルダウンや漢字の候補選択UIはありません。作者は「動作を自分で設定」で、別の文章と動作の対応を作成できます。

## 操作

- **← → / A D**：移動
- **Space / ↑ / W**：ジャンプ。空中で押し直すと、残り回数を使って1回だけ追加ジャンプ
- **停止**：時間を止め、ステージの空欄を書きかえる
- **やり直し**：新しい挑戦を開始し、位置と残り回数をリセット
- ステージ番号：その景の初期状態から開始

文字の線だけに乗れ、字の空白は通り抜けられます。

## ステージを作る

トップ画面の **「ステージ作成」** から、現在のステージを元に編集を始められます。「新しいステージ」で初期マップに戻せます。初期10ステージそのものは編集されません。

1. **地面**：25pxグリッド上でドラッグして長方形を描きます。クリックだけなら25px四方の地面になります。
2. **スタート／ゴール**：地面の上端をクリックして配置します。
3. **入力欄**：クリックした位置へ、文章と空欄をまとめて配置します。空欄は一つです。
4. ステージ名、ルールの設定、編集用の漢字、漢字の大きさを設定します。総ジャンプ回数も指定できます。
5. **このステージを試す**：構造をチェックしたあと試遊できます。「編集に戻る」で下書きに戻ります。試遊中の漢字変更やキャラクターの移動は編集データを書き換えません。
6. **端末に保存**：このブラウザのローカルストレージに保存します。既存の自作ステージを開いて保存すると更新、「コピーを保存」なら別のステージとして保存します。

地面の削除、元に戻す／やり直すに対応しています。保存したステージは画面下の一覧から開けます。削除した場合、直前の一件を戻せます。

### 書き出しと読み込み

**JSONを書き出す**でファイルに保存し、**JSONを読み込む**で他の端末・ブラウザへ持ち出せます。読み込んだ段階では下書きなので、端末に残すには「端末に保存」を押してください。

保存は最大20ステージ、地面は最大60長方形です。JSONは100KB以内。形式・座標・地面・ルール・入力欄の位置と字形を確認し、不正なファイルで既存データを上書きしません。ブラウザに保存できない場合は理由を表示し、下書きを残すのでJSONで書き出せます。

検証は構造・配置のチェックです。クリア可能性の自動判定は行わないため、作者が試遊して確かめてください。保存先はこのブラウザです。公開サーバーへの自作ステージ投稿・同期機能はありません。

## 字形と当たり判定

UIには **DotGothic16** を同梱。足場には広い漢字範囲を収録した **Noto Sans CJK JP Thin（ウェイト100）** を32ドットにラスタライズした角張った字形を使います。表示する同じスプライトから衝突マスクを作り、文字の周りの四角い箱には当たり判定を付けません。細い線を抜けないよう、移動は最大1pxずつ判定します。

フォントはローカル配信で、外部サービスやAPIは使いません。初回はフォント読み込みを待ちます。取得できない場合は端末の字体を同じ処理で使用します。珍しい字はフォント収録範囲に応じて代替字体になる場合があります。Canvas.roundRectには依存しません。

ビルド・追加パッケージは不要です。


GitHub Pagesは **Settings → Pages → Deploy from a branch → main / (root)** で配信できます。

## 構成

- `engine.js`：文の意味判定、総ジャンプ数、固定の一文字、ステージ検証、衝突・移動
- `game.js`：ドット字形、描画、ステージ内の入力欄、プレイ画面
- `editor.js`：編集・履歴・試遊・ローカル保存・ステージファイル
- `index.html` / `style.css`：画面とレスポンシブ表示
- `assets/`：フォント・出典・ライセンス

既存景のクリア記録と自作ステージは、別々のキーでブラウザのローカルストレージに保存します。未保存の編集や、プレイ中の進行はページを開き直すと失われます。

## ルール文と STAGE の割り当て

編集画面のルール文は自由入力です。空欄は `［字］` を一つだけ書きます。ジャンプ回数（例：`合計［字］回ジャンプできる。`）と体の変化（例：`体が［字］くなる。`）を解釈でき、未対応の意味や不成立の文章は保存・反映を拒否します。任意の自然言語を解釈するAIは利用していません。

「反映する STAGE」を選び「この内容を STAGE に設定」で、編集内容のコピーをその番号に設定します。端末内保存、JSON、STAGE 割り当ては別々です。割り当て後に下書きを編集した場合は再設定してください。設定はこのブラウザ内に保持し、他の利用者の公開サイトには反映しません。「初期状態に戻す」で元のステージに戻せます。

トップ画面で「ステージ一覧」または「ステージ作成」を選びます。一覧の STAGE カードをクリックすると挑戦画面が開きます。挑戦画面にはステージ名・盤面・開始／停止・やり直し・残りジャンプ回数・右上のメニューを表示します。漢字を書き換えて「開始」で適用でき、Enterでの確定にも対応します。未対応の入力時のみエラーを表示します。右上のメニュー（または Esc）で一時停止します。「最初から」で漢字を未入力にし、位置・ジャンプ回数も初期状態に戻り、「ステージ選択に戻る」で一覧に戻ります。「閉じる」でメニューを開く前のプレイを再開します。試遊中は「編集に戻る」も選べます。一覧にはブラウザ内で割り当てたステージとクリア状態を表示します。

ステージ選択後と試遊開始時は漢字の入力欄・足場を空にします。漢字が確定するまで開始ボタンは無効で、残り回数は未確定（—）と表示します。作成画面の編集用漢字は編集・形状検証用として維持します。一覧のプレビューには漢字を描きません。

## ステージ作成：ルール・大きさ・仕掛け

「ルールの設定」は3種類です。

- 文章から判定：従来のジャンプ回数・体の変化を使います。
- ルールなし：文章を描かず入力枠だけを表示し、任意の漢字一文字を足場にできます。総ジャンプ回数は作成画面の設定値です。
- 動作を自分で設定：文章の `［字］` と動作の対応をブラウザで設定します。行ごとに漢字、変える項目、値を指定し、同じ漢字に複数の項目を設定できます。`*` はすべての漢字、数値の決め方「入力した漢数字の値」は漢数字を数値として解釈します。特定の漢字の設定は `*` の設定より優先します。未設定の文字や範囲外の値は適用せず、元の状態を維持します。

自分で設定できる項目：総ジャンプ回数、移動速度、ジャンプ力、重力の強さ、重力の向き（上下左右・奥）、体の幅・高さ・色・透明度。主人公の基本色は黒で、色・透明度のルールも装束に反映します。「重力の向きの例を読み込む」で編集可能な5方向の対応例を作れます。動作データはステージの保存・割り当て・JSONに含まれ、コードの編集は不要です。任意のプログラムや未知の物理動作を実行する機能ではありません。

漢字の大きさはスライダーか数値欄で40〜2000pxに設定できます。道具「入力欄」で漢字を置きたい中心をクリックしてください。画面外の部分は切り取り、見える線だけが足場になります。大きい漢字は地面と重ねられますが、入力する漢字の線がスタートのキャラクターに重なる場合は反映を拒否します。大きい漢字や画面端に置いた漢字の入力欄・ルール文は、操作しやすいよう画面上部に表示します。

追加した道具はいずれもドラッグして配置でき、「消す」や元に戻す・やり直すにも対応します。

- 壊れる床：乗った合計秒数で消えます（0.1〜30秒）。配置前に秒数を設定します。メニュー中はタイマーが止まり、リトライ・死亡・漢字変更で復活します。
- 蔦：接触中に ↑↓ / W S で登り降りし、キーを離すとその場でつかまります。左右で離れられ、Spaceでジャンプできます。ジャンプ回数は回復しません。
- トゲ：触れると同じ漢字・ルールを保持したまま、自動的にスタートから再挑戦します。

左右向きの重力のとき、←→ / A D は縦方向の移動、Spaceは重力と逆向きのジャンプです。蔦にいる間の左右移動は重力にかかわらず横方向です。通常の重力では従来どおり左右移動します。

## ステージ数・番号サムネイル・奥の重力

ステージ一覧のサムネイルは番号だけを表示します。一覧上部の「ステージ数」で1〜100を指定し「変更」を押してください。初期値は10です。作成画面の割り当て先も連動し、減らした番号の自作データは削除せず、数を増やすと再び使えます。数と割り当てはブラウザ内に保存します。11番以降の未設定ステージは最初のステージのマップを使い、作者が差し替えられます。初期のSTAGE 6は単色黒の背景で、作成画面でも背景を選べます。

「重力の向きが［字］になる。」に「奥」を入力すると、通常時から描かれているビルの側面へ奥行き方向に落ち、その壁面上で4方向に移動できます。主人公は頭側から見た姿で、小さくなる落下アニメーションを経て着地します。ビルは以前より大きく手前寄りに描き、実行時にビルの位置・色・数を切り替えません。同じ側面データを描画と移動判定に使います。

奥の面では ↑↓←→ / W S A D で壁面を移動し、Spaceで壁面間をジャンプします。↑はジャンプにはなりません。壁面のない場所では奥へ落下し、通常の地面・棘・蔦・漢字には乗れません。手前の地面・仕掛け・漢字・EXITは通常時と同じ濃さと位置で表示します。EXITの奥にあるビル側面に立ち、そこからジャンプして手前へ抜ける場合のみクリアします。近づくだけ・立つだけ・空中で追加ジャンプするだけではクリアしません。ジャンプは着地から1回＋空中追加1回で、ステージ全体の残り回数も消費します。失敗すると同じ漢字のまま自動リスタートします。

動作編集の重力の向きでも「奥」を選べます。STAGE 10では「奥」「下」を使え、8回のジャンプで各ビルの側面を渡り、最後の1回でEXITへ抜けてクリアできる経路を確認しています。黒地の背景にも月を描きます。ビルを新しく出さず、奥の面の足場もありません。

## タイル配置とトゲの向き

地面と仕掛けは画面上端（y=0）まで配置できます。プレイヤーの上端制限もy=0です。トゲは配置前に上下左右の向き、または0〜359度の角度を指定します（0＝上、90＝右）。角度は保存・STAGE割り当て・JSONに含まれます。トゲの見た目と接触判定には同じ三角形を使い、三角形の外側の空白には接触しません。

地面は重なる・隣接する長方形をまとめて描き、内部の継ぎ目を表示しません。模様はステージ座標に合わせています。トゲは25px単位の三角形を敷き詰めます。1マスずつ隣接配置しても、まとめて同じ範囲に置いても同じ見た目になります。

## 忍者・自動リスタート・マス消去

タイトルは「字形活路」です。主人公は頭巾と鉢巻きを着けた忍者で、走り・空中・蔦につかまる姿勢を切り替えます。基本の装束は黒です。「体が［字］くなる。」の赤・青・白・黒などや、作者が設定した色・透明度の動作も反映します。移動の加速・減速は素早く反応する設定です。

落下やトゲで失敗すると、同じ漢字・足場・ルールを保ち、自動的にスタートから再開します。総ジャンプ回数と壊れる床は各試行の初期状態に戻ります。失敗時には入力画面へ戻りません。「やり直し」またはメニューの「最初から」で漢字を空欄にして、入力し直せます。

消しゴムは25×25pxの1マスだけを消し、ドラッグすると通ったマスを順に消します。大きな地面やトゲはそのマスの部分だけが切り取られます。元に戻す・やり直すに対応し、回転したトゲも消去範囲外の形と当たり判定を保持します。古いマップのグリッドに合わない部分も切り取れるようにし、細分化後の地面・仕掛けは各800部分、JSON読み込みは512KBまで対応します。

主人公の目と顔のスリットは描かず、頭巾・装束はすべて基本色の黒（またはルールによる指定色）のシルエットです。通常時の忍者姿と、奥の面の頭側から見た姿の両方に適用します。

## 一覧への移動と大きな漢字の表示

編集画面上部の「ステージ一覧へ」で直接一覧に移動できます。編集中の下書きはページ内に保持し、トップの「ステージ作成」で戻ると復帰します（再読み込みをまたぐ保存には「端末に保存」またはJSONを使います）。

大きい漢字や画面端の入力欄を操作するため、入力枠を上部に表示する場合がありますが、小さい漢字のコピーは描きません。実際に足場となる漢字だけを一つ描きます。

ビルは地形・棘よりコントラストを抑えた背景色で統一し、窓も控えめに描きます。STAGE 10の初期ジャンプ回数は、最後のEXITジャンプを含め9回です。

## 五界の旅人：探索型RPG

5世界それぞれに80×60マスのフィールドと48×36マスのダンジョン、拠点、標3個、ダンジョンの封印3個、ボスを用意しています。冒険の敵は25種類、練習用の木人が1種類、依頼は15件、宝箱は45個、採集地点は30個です。マップ・魔物のドット絵・戦闘背景はローカルのCanvas描画です。

開始画面は名前入力と「ゲームを開始する」のみにしています。保存がある場合は続きから再開します。新しく始める操作とタイトルへの移動は冒険中の「メニュー」、制作室もメニュー内にあります。

新しい冒険では自分で町の北西の王の館に入り、王・文成のところまで歩き、Spaceで話しかけます。王の依頼を受け、南の道場で漢字の使い方を練習すると町の南の門から原野へ出られます。世界から漢字を奪った魔王・墨喰いを倒し、姫・紬を救う物語です。人物との会話はドット絵の挿絵付きで、Spaceまたは画面のボタンで次のセリフへ進みます。選択肢が複数ある場合は選びます。はじまりの町は24×26マスの専用マップで、家・宿・商店・王の館・道場の5つの室内（各12×12マス）があります。入口のマスに歩いて触れると入り、室内南端の出口で町へ戻ります。建物の屋根と壁を含む全描画範囲は入口以外歩けず、地形を塗り替えても建物の上には立てません。町とすべての室内は遭遇率0・出現する敵なしです。木人との戦闘は師範に話して開始する練習で、ダメージを受けず、報酬・経験値・討伐数は増えず、練習後に全回復します。

次の世界は前の世界の核を解放すると開きます。旅の記録には解放済みの世界だけを表示し、冒険の開始時に世界を選ぶ操作はありません。最後の王城では魔王を倒し、姫との会話で物語を結びます。

戦闘への移行は黒へのフェードとWeb Audioによる効果音を使います。音はブラウザが再生を許可した場合に鳴ります。勝利後は約1.8秒間報酬を戦闘画面に表示し、暗転後にマップ・続きの会話へ移ります。切り替え中は重複入力を止め、画面を離れた場合は残ったタイマーを無効にします。保存キーは従来のままです。以前の標準マップを含む制作データには町・室内・チュートリアルを補い、対応表の編集や独自フラグなどを維持します。以前の最初の拠点にいるセーブは、新しい町へ移して再開します。制作室で保存した独自プロジェクトにはそのプロジェクトの物語を使用します。

冒険の流れ：拠点の案内人や依頼係と話す → フィールドの三つの標で守護者を倒す → 南東の門からダンジョンへ → 三つの封印を解く → 核の番人を倒す → 拠点東から次の世界へ。5世界目を終えると物語の目的が達成され、残った依頼や宝箱を探索できます。

HP・MP、レベルと経験値、装備、所持金、薬草・魔力回復・解毒、毒・火傷、属性術・回復術・待機に対応します（通常攻撃・道具・逃走などの内部処理は制作・テスト用に維持します）。火→木→水→火が有利（1.6倍）、逆は0.75倍、同属性は0.6倍。日と月は互いに1.6倍です。守護属性は被ダメージ側、術の属性は攻撃側に使います。物理攻撃は属性補正を受けません。敵は3ターンごとに強い属性攻撃を使い、防御はダメージを軽減してMPを3回復します。術は設定した漢字の画を選んで発動し、MPを選んだ画数だけ消費します。

剣士はHP・攻撃、魔術師はMP・術、探索者は会心・逃走が得意です。敗北時は所持金の10%を失って宿に戻り、物語のフラグと持ち物は維持します。

操作：矢印 / W A S D で移動、Space / Eで近くを調べます。マップ・依頼・道具・セーブ・漢字対応表・制作室は右上のメニューから。X / Escでメニューを開き、縦並びの項目を上下キーとEnterで選べます。普段はマップのみを表示し、HP・MP・所持金・能力はメニュー内で確認します。タッチ操作にも対応します。地図は探索した範囲を表示します。マップは384×288のキャンバス上に16ピクセル単位のタイルとオリジナルの人物・屋根・家具などを描き、拡大時の補間を無効にしたドット絵です。世界の核を解放すると、旅の記録から次の世界や以前の拠点へ移動できます。

セーブは `gokai-rpg-save-v1`、制作データは `gokai-rpg-project-v1` にブラウザ内保存します。戦闘途中は保存せず、戦闘終了・会話・移動・定期的な歩数で自動保存します。手動保存と開始ボタンからの続きの再開に対応します。保存に失敗した場合は画面に表示します。別端末との同期・通信対戦は行いません。

### 漢字と画数

戦闘前に常用漢字を1文字自由入力し、開始後はその戦闘中の漢字を固定します。レベル1の上限は1画、以後1レベルごとに1画増え、最大29画です。例えば「明」の1・2・3・4画は「日」（日属性攻撃、MP4）、5・6・7・8画は「月」（月属性攻撃、MP4）、1・2・4画は「口」（HP回復、MP3）です。戦闘画面で画番号を入力するか筆画を押して選びます。選択した筆画は黄色になり、出力漢字・技名・効果は発動後のログで初めて表示します。戦闘中は対応表や技一覧を表示しません。空欄で発動ボタンを押すと待機し、身を守ってMPを3回復します。対応しない組み合わせやMP不足ではターンもMPも消費しません。

常用漢字2,136字を収録し、全画の自己対応を含む15,967件の対応を登録しています。うち1,895字は複数画からなる部分漢字を持ちます。KanjiVGの構造・画種と確認済みの削除規則から生成した保守的な登録表であり、成立しうる全組み合わせを認識するものではありません。氵を3画で水にする等の部首の意味による置換はしません。出典・制約・再生成方法は [データ説明](assets/kanji/README.md) を参照してください。

出力漢字2,136字それぞれに効果を設定しています。200字は攻撃・回復・防御・状態変化などの初期設定、残りは画数に応じた無属性攻撃で、制作室で変更できます。同じ出力漢字なら元の漢字にかかわらず同じ効果になります。

戦闘外の「漢字・画数」画面には、元字とそこから作れる漢字を検索・ページ送りできる全2,136字の一覧があります。元字を入力すると画番号ごとの対応を表示し、追加・変更・削除・元字単位の初期状態への復元ができます。選択画数と出力字の画数が一致する常用漢字のみ登録でき、編集内容はこの端末の制作プロジェクトに保存して実際の戦闘判定に使います。制作室のプロジェクトJSONに含めて出力・読み込みでき、編集後の対応表CSVもダウンロードできます。初期データは [画数対応CSV](assets/kanji/stroke-map.csv) と [効果CSV](assets/kanji/effects.csv) をダウンロードできます。所持金はG単位で管理し、買い物・戦闘報酬・依頼・敗北・イベントの増減を履歴表示します。「金」の術は勝利時の獲得金を増やします。

### RPG制作室

タイトル画面の「RPG制作室」から編集できます。

- マップ：地形の塗り・消去、サイズ変更、開始位置、出現する敵と遭遇率、NPC・宝箱・門・宿・商店・イベントを配置。
- 敵：名前、16種の見た目テンプレート、配色、5属性、HP・攻撃・守備・報酬・ボス扱いを設定。
- キャラ：名前、職業風の服装、配色、標準の会話を設定。
- 会話：文章と選択肢、次の会話、表示条件と実行する動作を編集。
- 漢字の効果：常用漢字ごとに効果名・種類・属性・威力・持続を設定。MPコストは選んだ画数で固定。
- フラグ：ON/OFFと数値を作成し、「等しい・等しくない・以上・以下」で条件分岐を設定。条件はすべて満たす方式。

動作はフラグの設定・加算、所持金の増減、道具の付与、全回復、戦闘、マップ移動、会話への移動です。上から順に実行し、戦闘の後ろに置いた動作は勝利時だけ続きます。敗北や逃走では続きません。参照先のないイベントや型の合わない条件などは保存・試遊・JSON読み込み時に拒否します。任意のJavaScriptは実行しません。

制作の保存、元に戻す・やり直す、プロジェクトJSON（4MBまで）の出力・読み込みに対応します。制作変更はブラウザ内のプロジェクトに保存し、他の利用者の公開データは書き換えません。試遊は選んだマップの開始位置から新しいキャラで行い、冒険のセーブを上書きせず、制作室へ戻れます。新しいマップへ本編から移動させるには、既存マップのイベントに移動の動作を設定してください。

### 長さと確認範囲

各世界は探索・依頼・ダンジョンを含む30分程度を目標に設計していますが、実プレイの所要時間は未計測です。道を知っている場合や会話を飛ばす場合は短くなります。150分の通しプレイを検証済みとはしていません。待ち時間を強制するタイマーはありません。

全イベントへの歩行経路、全5世界の必須戦闘と成長に必要な通常戦闘を含むクリア、属性・MP・勝敗後の条件・報酬、セーブ復元・不正データ拒否を自動テストします。ブラウザでは新しい敵・キャラ・会話・フラグ・マップを実際に作り、条件分岐から作成した敵と戦う試遊、保存とJSON往復、本編の開始と継続、会話・地図・術・モバイル表示を確認しています。

構成：`rpg-data.js` が初期の世界・物語、`rpg-engine.js` が戦闘とイベント・保存検証、`rpg-art.js` がマップと敵・キャラの描画、`rpg-studio.js` が制作ツール、`rpg.js` がゲーム画面、`rpg.html` / `rpg.css` がUIです。追加の依存関係やビルドは不要で、PythonのHTTPサーバーなどで配信できます。

## ことばのスケルトン

ゲーム選択から `skeleton.html` を開く、同じ端末で交互に操作する2人対戦です。既存の字形活路・RPGのデータや保存キーとは独立しています。

- 盤面は7×7。先攻は上下、後攻は左右の端をつなぎます。
- 「を」を除く基本のひらがなと長音符の46枠を両者で共有し、1手で1枠を1マスに置きます。濁音・半濁音・小文字への変形は判定時だけ可能で、元字の使用枠は共通です。
- 配置直後に「判定」または「相手の手番へ」を選びます。判定では相手の置いた文字も含め、使用するマスだけを指定します。
- 選択したマスが上下左右で一つにつながり、目的の両端に届くこと。横は左→右、縦は上→下の2文字以上の最大連続列をすべて辞書と照合します。選ばない文字は無視します。
- 中央★は最初からあり、濁音・半濁音・小文字・「を」も含めたひらがなか長音符の1文字を指定できます。判定前に中央の文字を必ず指定します。1マスの文字は縦横で共通です。中央は46枠を消費しません。
- 成立すれば判定した人、失敗すれば相手の勝ち。判定を確定する前は選択を取り消せます。46手目も判定でき、判定せず終えれば引き分けです。

単語判定はネット公開のJMdict（EDRDG）の2026-11-02版を元にした154,728件の読みを使います。ゲームサイトから辞書JSONを取得して完全一致で照合し、取得後はメモリに保持します。通信エラー・不正な辞書応答では勝敗を付けずに選択状態へ戻します。読み・長さ・出典・ライセンス・再生成は [辞書の説明](assets/skeleton/README.md) を参照してください。

対局は `kana-skeleton-save-v1` に自動保存し、再読み込みで復元します。配置・手番・選択・判定中の入力を制限し、判定中に再読み込みした場合は未確定の選択状態へ戻します。PCのクリック・盤面の矢印移動、タッチ操作に対応します。
