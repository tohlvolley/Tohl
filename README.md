# 言ノ葉の道 — Tohl

好きな漢字の**字形そのもの**を足場にし、文章の空欄に漢字を入力してルールを書きかえる、ブラウザ用アクションパズルです。全4景。

## 遊び方

1. 筆箱に好きな漢字を一文字入力して「選ぶ」。おすすめ以外の「夢」「橋」「猫」「龍」なども配置できます。
2. ゲーム画面をクリックし、その場所を中心に文字を配置します。大きさは100〜200で変更できます。
3. 「旅をはじめる」で開始。文字の**色がついた線にだけ**乗れます。「回」「口」の内側の空白や、「川」の線の隙間は通り抜けられます。
4. 朱色の門へたどり着けばクリア。最初に置いてある文字は回収・変更できます。必要な足場は自分で足してください。

### 操作

- **← → / A D**：移動
- **Space / ↑ / W**：ジャンプ。空中で押し直すと、ルールの回数まで追加ジャンプ
- **配置に戻る**：一時停止して、文字やルールを編集
- **配置した文字をクリック / 右クリック**：回収
- **スタートに戻る**：旅人だけを戻す。配置とルールは維持
- **文字を消す**：文字をすべて回収し、旅人を戻す。ルールは維持
- ステージの番号：その景を初期配置・初期ルールで開始

スマートフォンは画面下の左右・ジャンプボタンで操作できます。日本語入力は変換を確定してから「選ぶ」「ルールを反映」を押してください。

## 入力するルール

### 「［三］回まで飛べる。」

着地するまでの合計ジャンプ回数です。最初のジャンプも含み、着地すると回数が回復します。

- 一：1回、二：2回、三：3回
- 十：10回、二十三：23回、百：100回
- 零 / 〇：ジャンプ不可

零〜九千九百九十九に対応。アラビア数字や数字以外の漢字はエラーとして表示します。長押しで回数を連続消費することはありません。

### 「重力は［軽］。」

- 軽：落下がゆっくりになり、高く跳べる
- 並：通常の重力
- 重：落下が速くなり、ジャンプが低くなる

「ルールを反映」で適用します。文字の配置を残し、旅人をスタートに戻します。不正な入力では適用中のルールは変わりません。

配置した文字自体には、前の試作版の火・水などの属性効果はありません。どの漢字も、その字形が足場になります。

## 細い字体と当たり判定

Noto Sans CJK JP **Thin（ウェイト100）** を同梱しています。追加のフォントサービスやAPIは使いません。初回は約9.2MBのフォント読み込みを待ちます。フォントには収録範囲があるため、非常に珍しい漢字は端末の代替字体になる場合があります。

文字を透明なCanvasに描き、アルファ値から画素単位の衝突マスクを作ります。描画にも同じCanvasを使うため、字形と当たり判定が一致します。文字の周囲に四角い足場はありません。細い線をすり抜けないよう、移動は最大1pxずつ判定します。編集時の点線の枠は選択範囲で、足場ではありません。

Safariを含むブラウザ向けに、Canvas.roundRectには依存しません。フォント取得に失敗した場合は端末の字体で続行し、その同じ字形から当たり判定を作ります。

## 起動

ビルド・追加パッケージのインストールは不要です。

```sh
cd /workspace/Tohl
python3 -m http.server 8000 --bind 0.0.0.0
```

自分のPCのブラウザで `http://localhost:8000` を開きます。同梱フォントの読み込みのため、ファイルを直接開くよりHTTPサーバーの使用を推奨します。

GitHub Pagesでは **Settings → Pages → Deploy from a branch → main / (root)** で配信できます。

## テスト

Node.js 18以降で、追加依存関係なしに実行できます。

```sh
node --test tests/engine.test.cjs
```

漢字・漢数字の入力、空白部分の通過、1pxの線への着地、囲みの内側での着地、多段ジャンプの上限と回復、重力、配置制約、回収、一時停止、落下、ゴール判定を検証します。

実ブラウザでは、同梱フォントの実際の字形を使った当たり判定、漢字入力・配置、多段ジャンプ、ルール変更、モバイル表示と各ステージのクリア経路を検証しています。Safari実機の検証は別途必要です。

## ファイル構成

- `engine.js`：ステージ、漢数字の解釈、画素マスクの照会、移動・衝突・ジャンプのルール
- `game.js`：フォント読み込み、字形のラスタライズ、Canvas描画、入力と画面管理
- `index.html` / `style.css`：画面とレスポンシブ表示
- `assets/`：SIL Open Font Licenseのフォントとライセンス

クリア記録はブラウザのローカルストレージに保存します。配置や編集中のルールはページを開き直すと初期状態になります。
