# Tohl — スライドパズル

数字を順番に並べる、ブラウザ用のスライドパズルです。
3×3 / 4×4 の難易度、手数、タイマー、難易度別の最少手数記録に対応しています。

## 起動

追加の依存関係は不要です。`index.html` をブラウザで開くか、次のコマンドを実行します。

```sh
cd /workspace/Tohl
python3 -m http.server 8000 --bind 0.0.0.0
```

タイルをクリック・タップ、または矢印キーで移動します。
左上から数字を順番に並べ、右下を空けるとクリアです。
記録はブラウザのローカルストレージに保存されます。
