# 言ノ葉の道 — RULE RUNNER

文章の空欄に入力した**漢字一文字が、ルールと唯一の足場に同時に反映される**ブラウザ用アクションパズルです。全4景。画面・キャラクター・漢字は、角張ったデジタル／ドット絵調です。

## 遊び方

1. ルール文の空欄に、漢字を一文字自由入力します。プルダウン、候補リスト、別の足場入力欄はありません。
2. 文の意味を判定します。成立しない／効果を解釈できない入力では、理由を表示して反映ボタンを無効にします。
3. 「文と一文字を反映」を押すと、ルールとステージの一文字が一緒に切り替わります。
4. ステージをクリックして、その一文字を移動します。追加配置はできません。
5. 「旅をはじめる」で開始し、出口ゲートへたどり着けばクリアです。

### 文と足場の例

- **「三回まで飛べる。」**：着地まで合計3回ジャンプでき、足場も「三」が一つだけになります。
- **「十回まで飛べる。」**：合計10回。足場は「十」に置き換わります。
- **「猫回まで飛べる。」**：具体的な回数として解釈できないため反映できません。現在のルール・足場・旅人は変わりません。
- **「体が速くなる。」**：移動速度が上がり、足場は「速」になります。
- **「体が赤くなる。」**：体の色が赤くなり、足場は「赤」になります。

文は景ごとに決まっています。第一景・最終景は「［ ］回まで飛べる。」、第二景・第三景は「体が［ ］くなる。」です。自由な文章全般を理解するAIではなく、`evaluateRule` が各文の意味を解釈します。未対応の意味は「反映できない」と表示し、文が成立すると断定しません。

入力は漢字一文字です。「二十三」など複数字の数詞は配置条件に合わないため反映できません。一・二・三などの漢数字に加え、十・百・千・万・億・兆、壱・弐などの大字も解釈します。零／〇ではジャンプできなくなります。体の文では速さ、重力、跳ぶ力、幅・高さ、色などの変化を解釈します。

日本語変換を確定してから反映してください。入力途中や未反映の文字では、適用中の足場とルールは変わりません。

## 操作

- **← → / A D**：移動
- **Space / ↑ / W**：ジャンプ。空中で押し直すと、ルールの回数まで追加ジャンプ
- **配置に戻る**：一時停止して文や足場の位置を編集
- **画面をクリック**：適用中の一文字をその場所へ移動。文字は増えません
- **文字の大きさ**：唯一の文字を100〜200で拡大・縮小
- **スタートに戻る**：旅人だけを戻す。文・ルール・文字の配置を維持
- **位置を戻す**：一文字の位置と大きさをその景の初期値へ戻す。適用中の文字と文は維持
- ステージ番号：その景の初期状態から開始

着地するとジャンプ回数が回復します。スマートフォンでは左右・ジャンプボタンを使えます。文字の線だけに乗れ、文字の空白は通り抜けられます。落下しても文字とルールは残ります。

## ドット字形と当たり判定

UIには **DotGothic16** を同梱。足場の漢字には、広い漢字範囲を収録した **Noto Sans CJK JP Thin（ウェイト100）** を32ドットにラスタライズし、アンチエイリアスを除いて拡大した角張った字形を使います。細い線を維持しつつ、デジタルな輪郭にしています。フォントのライセンスは `assets/` に収録しています。

描画する同じスプライトのアルファ値から衝突マスクを作ります。文字の周囲に四角い足場はありません。細い線をすり抜けないよう、移動は最大1pxずつ判定します。編集時の点線枠は移動先のガイドで、二つ目の文字や足場ではありません。

フォントはローカル配信され、外部のフォントサービスやAPIに接続しません。初回はフォントの読み込みを待ちます。取得できなければ端末の字体を同じドット処理に通して続行します。非常に珍しい字は収録範囲に応じて代替字体になる場合があります。Canvas.roundRectには依存しません。

## 起動と公開

ビルド・追加パッケージは不要です。

```sh
cd /workspace/Tohl
python3 -m http.server 8000 --bind 0.0.0.0
```

自分のPCのブラウザで `http://localhost:8000` を開きます。フォントを確実に読み込むため、HTTPサーバー経由を推奨します。

GitHub Pagesは **Settings → Pages → Deploy from a branch → main / (root)** で配信できます。

## テスト

Node.js 18以降で、追加依存関係なしに実行できます。

```sh
node --test tests/engine.test.cjs
```

文の解釈、漢字一文字の制約、単一配置、不正な文や配置の拒否、ルールと字形の同時更新、移動・リサイズ、細い線と空白の衝突、ジャンプ制限、体への効果、落下・停止・ゴール判定を検証します。

ブラウザでは実際の字形で、入力と反映ボタン、文と唯一の漢字の連動、候補選択UIが存在しないこと、ドット字形、モバイル表示、4景それぞれの一文字だけを使うクリア経路を確認しています。Safari実機での検証は別途必要です。

## 構成

- `engine.js`：文の意味判定、単一字形の管理、ステージ、衝突・移動のルール
- `game.js`：ドット字形生成、デジタル風描画、入力、未反映／適用中の状態管理
- `index.html` / `style.css`：画面・文章欄・レスポンシブ表示
- `assets/`：フォント・出典・ライセンス

新しい文や効果は `evaluateRule` と `rulesFor` に追加します。クリア記録はブラウザのローカルストレージに保存します。ページを開き直すと文と配置は初期状態になります。
