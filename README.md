# 言ノ葉の道 — RULE RUNNER

ステージ内の文章の空欄に漢字を一文字入力すると、その文字がルールと唯一の足場になる、ドット絵調のブラウザ用パズルです。初期10ステージと、ステージ作成機能を収録しています。

## ステージ内のルール

文章も入力欄もステージ内に配置されています。入力欄の位置と大きさはステージ制作者が決め、プレイヤーは移動できません。入力した漢字のドットだけが足場になり、文章のほかの文字はキャラクターと衝突しません。

1. ステージ内の空欄をクリックし、漢字一文字を自由入力します。
2. 日本語変換を確定したあと、Enterまたは「開始」で反映します。
3. 漢字が変わると、キャラクターをスタートに戻してジャンプ回数をリセットします。不成立・解釈できない入力は反映しません。
4. 「開始」でプレイを開始。出口ゲートに着けばクリアです。

未確定の入力はプレビューです。開始時に確定するため、見た目と当たり判定が食い違ったまま遊ぶことはありません。

### ジャンプはステージ全体の予算

**「このステージで三回まで飛べる。」なら、スタートからゴールまで合計3回です。着地しても残り回数は戻りません。** 地上からのジャンプに加え、空中では追加1回までジャンプできます。着地で空中の追加回数だけが戻り、ステージ全体の残り回数は戻りません。

- 一・二・三・十・百などの漢数字を解釈します。万・億・兆や壱・弐などにも対応します。
- 零／〇ならジャンプできません。
- 「二十三」のような複数字は、一文字の配置条件に合わないため反映できません。
- 同じ漢字の再確定、一時停止、着地では回数を回復できません。
- 漢字の変更、リトライ、落下後の再挑戦、新しいステージ開始で、スタートから新しい挑戦になります。

「体が［字］くなる。」の景では、意味に応じて移動速度・重力・大きさ・色などが変わります。その景の総ジャンプ回数はステージ設定によります。いずれの型でも、文を解釈できない入力は反映せず、現在のキャラクター・足場・ルールを保ちます。

任意の文章全般を理解するAIではありません。現在の文章の型は「このステージで［字］回まで飛べる。」「体が［字］くなる。」の2種類です。未対応の意味も解釈できない旨を表示します。プレイヤー向けのプルダウンや漢字の候補選択UIはありません。作者は「動作を自分で設定」で、別の文章と動作の対応を作成できます。

## 操作

- **← → / A D**：移動
- **Space / ↑ / W**：ジャンプ。空中で押し直すと、残り回数を使って1回だけ追加ジャンプ
- **停止**：時間を止め、ステージの空欄を書きかえる
- **やり直し**：新しい挑戦を開始し、位置と残り回数をリセット
- ステージ番号：その景の初期状態から開始

文字の線だけに乗れ、字の空白は通り抜けられます。

## ステージを作る

トップ画面の **「ステージ作成」** から、現在のステージを元に編集を始められます。「新しいステージ」で初期マップに戻せます。初期10ステージそのものは編集されません。

1. **地面**：25pxグリッド上でドラッグして長方形を描きます。クリックだけなら25px四方の地面になります。
2. **スタート／ゴール**：地面の上端をクリックして配置します。
3. **入力欄**：クリックした位置へ、文章と空欄をまとめて配置します。空欄は一つです。
4. ステージ名、ルールの設定、編集用の漢字、漢字の大きさを設定します。総ジャンプ回数も指定できます。
5. **このステージを試す**：構造をチェックしたあと試遊できます。「編集に戻る」で下書きに戻ります。試遊中の漢字変更やキャラクターの移動は編集データを書き換えません。
6. **端末に保存**：このブラウザのローカルストレージに保存します。既存の自作ステージを開いて保存すると更新、「コピーを保存」なら別のステージとして保存します。

地面の削除、元に戻す／やり直すに対応しています。保存したステージは画面下の一覧から開けます。削除した場合、直前の一件を戻せます。

### 書き出しと読み込み

**JSONを書き出す**でファイルに保存し、**JSONを読み込む**で他の端末・ブラウザへ持ち出せます。読み込んだ段階では下書きなので、端末に残すには「端末に保存」を押してください。

保存は最大20ステージ、地面は最大60長方形です。JSONは100KB以内。形式・座標・地面・ルール・入力欄の位置と字形を確認し、不正なファイルで既存データを上書きしません。ブラウザに保存できない場合は理由を表示し、下書きを残すのでJSONで書き出せます。

検証は構造・配置のチェックです。クリア可能性の自動判定は行わないため、作者が試遊して確かめてください。保存先はこのブラウザです。公開サーバーへの自作ステージ投稿・同期機能はありません。

## 字形と当たり判定

UIには **DotGothic16** を同梱。足場には広い漢字範囲を収録した **Noto Sans CJK JP Thin（ウェイト100）** を32ドットにラスタライズした角張った字形を使います。表示する同じスプライトから衝突マスクを作り、文字の周りの四角い箱には当たり判定を付けません。細い線を抜けないよう、移動は最大1pxずつ判定します。

フォントはローカル配信で、外部サービスやAPIは使いません。初回はフォント読み込みを待ちます。取得できない場合は端末の字体を同じ処理で使用します。珍しい字はフォント収録範囲に応じて代替字体になる場合があります。Canvas.roundRectには依存しません。

## 起動と公開

ビルド・追加パッケージは不要です。

```sh
cd /workspace/Tohl
python3 -m http.server 8000 --bind 0.0.0.0
```

自分のPCで `http://localhost:8000` を開きます。フォントとステージファイルの読み込みのためHTTPサーバー経由を推奨します。

GitHub Pagesは **Settings → Pages → Deploy from a branch → main / (root)** で配信できます。

## 構成

- `engine.js`：文の意味判定、総ジャンプ数、固定の一文字、ステージ検証、衝突・移動
- `game.js`：ドット字形、描画、ステージ内の入力欄、プレイ画面
- `editor.js`：編集・履歴・試遊・ローカル保存・ステージファイル
- `index.html` / `style.css`：画面とレスポンシブ表示
- `assets/`：フォント・出典・ライセンス

既存景のクリア記録と自作ステージは、別々のキーでブラウザのローカルストレージに保存します。未保存の編集や、プレイ中の進行はページを開き直すと失われます。

## ルール文と STAGE の割り当て

編集画面のルール文は自由入力です。空欄は `［字］` を一つだけ書きます。ジャンプ回数（例：`合計［字］回ジャンプできる。`）と体の変化（例：`体が［字］くなる。`）を解釈でき、未対応の意味や不成立の文章は保存・反映を拒否します。任意の自然言語を解釈するAIは利用していません。

「反映する STAGE」を選び「この内容を STAGE に設定」で、編集内容のコピーをその番号に設定します。端末内保存、JSON、STAGE 割り当ては別々です。割り当て後に下書きを編集した場合は再設定してください。設定はこのブラウザ内に保持し、他の利用者の公開サイトには反映しません。「初期状態に戻す」で元のステージに戻せます。

トップ画面で「ステージ一覧」または「ステージ作成」を選びます。一覧の STAGE カードをクリックすると挑戦画面が開きます。挑戦画面にはステージ名・盤面・開始／停止・やり直し・残りジャンプ回数・右上のメニューを表示します。漢字を書き換えて「開始」で適用でき、Enterでの確定にも対応します。未対応の入力時のみエラーを表示します。右上のメニュー（または Esc）で一時停止します。「最初から」で漢字を未入力にし、位置・ジャンプ回数も初期状態に戻り、「ステージ選択に戻る」で一覧に戻ります。「閉じる」でメニューを開く前のプレイを再開します。試遊中は「編集に戻る」も選べます。一覧にはブラウザ内で割り当てたステージとクリア状態を表示します。

ステージ選択後と試遊開始時は漢字の入力欄・足場を空にします。漢字が確定するまで開始ボタンは無効で、残り回数は未確定（—）と表示します。作成画面の編集用漢字は編集・形状検証用として維持します。一覧のプレビューには漢字を描きません。

## ステージ作成：ルール・大きさ・仕掛け

「ルールの設定」は3種類です。

- 文章から判定：従来のジャンプ回数・体の変化を使います。
- ルールなし：文章を描かず入力枠だけを表示し、任意の漢字一文字を足場にできます。総ジャンプ回数は作成画面の設定値です。
- 動作を自分で設定：文章の `［字］` と動作の対応をブラウザで設定します。行ごとに漢字、変える項目、値を指定し、同じ漢字に複数の項目を設定できます。`*` はすべての漢字、数値の決め方「入力した漢数字の値」は漢数字を数値として解釈します。特定の漢字の設定は `*` の設定より優先します。未設定の文字や範囲外の値は適用せず、元の状態を維持します。

自分で設定できる項目：総ジャンプ回数、移動速度、ジャンプ力、重力の強さ、重力の向き（上下左右・奥）、体の幅・高さ。主人公の描画は黒一色固定です（以前に保存した色・透明度の動作データも読み込めますが、描画色は変更しません）。「重力の向きの例を読み込む」で編集可能な5方向の対応例を作れます。動作データはステージの保存・割り当て・JSONに含まれ、コードの編集は不要です。任意のプログラムや未知の物理動作を実行する機能ではありません。

漢字の大きさはスライダーか数値欄で40〜2000pxに設定できます。道具「入力欄」で漢字を置きたい中心をクリックしてください。画面外の部分は切り取り、見える線だけが足場になります。大きい漢字は地面と重ねられますが、入力する漢字の線がスタートのキャラクターに重なる場合は反映を拒否します。大きい漢字や画面端に置いた漢字の入力欄・ルール文は、操作しやすいよう画面上部に表示します。

追加した道具はいずれもドラッグして配置でき、「消す」や元に戻す・やり直すにも対応します。

- 壊れる床：乗った合計秒数で消えます（0.1〜30秒）。配置前に秒数を設定します。メニュー中はタイマーが止まり、リトライ・死亡・漢字変更で復活します。
- 蔦：接触中に ↑↓ / W S で登り降りし、キーを離すとその場でつかまります。左右で離れられ、Spaceでジャンプできます。ジャンプ回数は回復しません。
- トゲ：触れるとスタートに戻り、試行を停止します。開始を押すと再挑戦できます。

左右向きの重力のとき、←→ / A D は縦方向の移動、Spaceは重力と逆向きのジャンプです。蔦にいる間の左右移動は重力にかかわらず横方向です。通常の重力では従来どおり左右移動します。

## ステージ数・番号サムネイル・奥の重力

ステージ一覧のサムネイルは番号だけを表示します。一覧上部の「ステージ数」で1〜100を指定し「変更」を押してください。初期値は10です。作成画面の割り当て先も連動し、減らした番号の自作データは削除せず、数を増やすと再び使えます。数と割り当てはブラウザ内に保存します。11番以降の未設定ステージは最初のステージのマップを使い、作者が差し替えられます。初期のSTAGE 6は単色黒の背景で、作成画面でも背景を選べます。

「重力の向きが［字］になる。」に「奥」を入力すると、背景側のビルの屋上が着地できる足場になります。背景のビルと当たり判定は同じ屋上データを使っています。「奥」は背景側の足場に切り替える動作で、画面上では下向きに落下します。ビルの下からは通り抜けて上に登れ、上から落ちると屋上に着地します。左右移動・ジャンプ・総ジャンプ回数の制限はそのままです。通常の重力では背景のビルに乗れません。動作編集の重力の向きにも「奥」があり、入力文字との対応を作者が設定できます。STAGE 10は「奥」「下」を使えるサンプルです。
