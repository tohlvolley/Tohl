# 言ノ葉の道 — Tohl

漢字を足場として置き、その文字の意味で世界のルールを変えるアクションパズルの試作版です。4ステージを収録しています。

## 遊び方

1. 漢字を入力して「選ぶ」を押すか、筆箱の文字を選びます。
2. ゲーム画面の点線のマスをクリックして配置します。各ステージの「墨」が配置上限です。
3. 「旅をはじめる」を押し、キャラクターを朱色の門へ導きます。

- **← → / A D**：左右移動
- **Space / ↑ / W**：ジャンプ
- **配置に戻る**：一時停止して、文字を置き直す
- **配置した文字をクリック / 右クリック**：回収して墨を戻す
- **スタートに戻る**：旅人だけを戻す。配置と仕掛けの変化は維持
- **配置を消す**：ステージ全体を初期状態に戻す
- スマートフォンでは画面下の移動・ジャンプボタンを使います。

日本語入力中のEnterは変換の確定用です。確定後に「選ぶ」を押してください。

## 漢字のルール

| 漢字 | 効果 |
| --- | --- |
| 木 | 上に乗れる足場。隣の火で燃える。つながった木・蔦にも燃え広がる。 |
| 火 | 上下左右に隣接する木と蔦を燃やす。旅人が触れるとスタートへ戻る。 |
| 水 | 上下左右に隣接する火と、そこにつながる火を消す。足場にもなる。 |
| 風 | 上方6マスに上昇気流をつくる。左右にも少し広がる。 |
| 氷 | 滑る足場。木より速く走れ、遠くへ跳べる。火で溶けて水になり、消火も起こる。 |

文字同士の反応は配置時に発生します。未対応の漢字は配置できません。落下・火への接触で配置は失われません。クリア済みステージはブラウザのローカルストレージに保存します（保存が使えなくてもプレイ可能）。

## ローカル起動

追加パッケージや外部API、画像、フォントのダウンロードは不要です。

```sh
cd /workspace/Tohl
python3 -m http.server 8000 --bind 0.0.0.0
```

自分のPCでは `http://localhost:8000` を開いてください。`index.html` を直接ブラウザで開くこともできます。

## テスト

Node.js 18以降で、追加依存関係なしに実行できます。

```sh
node --test tests/engine.test.cjs
```

全4ステージの実際の物理演算によるクリア経路、文字の反応、配置制約、墨の回収、落下と火への接触、氷の慣性、一時停止を検証します。

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** で配信できます。ビルド処理は不要です。

- `engine.js`：ステージ定義、文字のルール、移動・衝突判定
- `game.js`：Canvas描画、入力、画面の状態管理
- `index.html` / `style.css`：画面構成とレスポンシブ表示

ステージや漢字を追加する場合は、まず `engine.js` の `LEVELS` / `WORDS` と反応処理を更新してください。
